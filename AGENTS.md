# Agent Instructions for YumaWorks/yumapro-yang

## ⚠️ Privacy and Access Control

This repository contains personal information and customer data.

**No AI agent, Copilot, or automated tool may access, inspect, read, or modify any files or data in this repository without explicit permission granted by the user in the current conversation.**

Before taking any action in this repository, you must:

1. Ask the user for explicit permission to access or modify files and data.
2. Wait for a clear confirmation before proceeding.
3. Limit your actions strictly to what the user has authorized.

If you have not received explicit permission in the current conversation, **stop and ask** — do not assume prior consent carries over.

## Branch Naming

When creating a branch for any repository in the `YumaWorks` organization, the branch name must follow this pattern:

```
{repo-name}-copilot-feature
```

For this repository, use:

```
yumapro-yang-copilot-feature
```

## General Rules

- Do not push directly to the default branch. Always open a pull request for review.
- Keep changes minimal and scoped to what the user explicitly requested.
- Do not share, log, or transmit any repository contents outside of the authorized task.
